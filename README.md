# 명지대학교 자연캠퍼스 자취 입지 건물 추천 웹 지도 (`mju-housing-map`)

> **라이브 웹 지도**: https://jaeyonni.github.io/mju-housing-map/

경기도 용인시 처인구 **역북동·남동 주거용 건물 1,910동**(자취용 1,744동 + 참고용 아파트 166동)을 대상으로, 7개 GIS 입지 요소의 가중치를 실시간으로 조절해 최적의 자취 건물을 탐색할 수 있는 **정적 웹 GIS 애플리케이션**입니다. (GIS 오전반 3조 최종 통합 데이터 기반)

---

## 주요 기능

- **실시간 7요소 가중 중첩 (Client-side Weighted Overlay)**
  - `가격`, `통학`, `편의`, `소음`, `경사`, `연식`, `치안` 7개 슬라이더를 움직이면 브라우저에서 모든 건물의 종합 점수와 추천 순위가 지연 없이 즉시 재계산됩니다.
  - **설문·시나리오 프리셋**: `전체(70명 설문)`, `남성 설문(n=40)`, `여성 설문(n=30)`, `가성비·통학`, `안심·편의`, `신축·저소음` 원클릭 전환을 지원합니다.
- **고성능 GPU 동기화 Canvas 지도 & 겹침 방지 라벨**
  - OpenStreetMap 일반지도를 기본 배경으로, 건물 폴리곤 1,910동·행정동 실선 경계·`명지대 정문` 기준 4단계 거리 반경(`직선 0.8 / 1.6 / 2.4 / 3.2km`)을 HiDPI Canvas로 렌더링하며 줌·드래그 시 배경지도와 부드럽게 동기화됩니다.
  - **통합 신호등 색상(빨강→노랑→초록)**: `총점(낮음→높음)`과 `환산월세(비쌈→저렴, P5~P85 백분위 스케일)` 모두 동일한 색상 규칙을 적용하며, 건물 위 텍스트(`없음 / 점수 / 월세 / 둘 다`)는 화면 겹침을 자동 회피합니다.
- **다중 필터 & 건물 상세 리포트**
  - 행정동(`역북동` / `남동`), 주거 유형(`자취용 전체` 기본 · `원룸` · `빌라` · `오피스텔` · `아파트(참고)`), 도로 평균 환산월세 예산 상한, 건물명/도로명 검색을 동시에 조합할 수 있습니다.
  - 전월세 시세는 법정 전환율 연 5.0% 기준 `환산월세`로 통일하되, 출처(`실측 / 도로추정 / IDW추정`)를 구분해 표기하며 실거래 미수집 아파트에는 별도 안내를 제공합니다.
  - 건물을 클릭하면 7개 요소별 점수(1~5점) 막대 그래프, 준공연도·층수·경사도·정문 직선거리 및 네이버/카카오 지도 검색 링크를 확인할 수 있습니다.
- **보조 GIS 레이어**
  - 우상단 도구바에서 `생활권(7개 권역)`, `경전철·주요시설`, `도로별 평균 시세(47개 도로)` 레이어를 켜고 끌 수 있습니다.
- **실시간 커뮤니티 · 건물 언급(태그) 연동**
  - 지도 좌상단(모바일은 우상단) `커뮤니티` 버튼을 누르면 버튼 그 자리에서 패널이 펼쳐지며(데스크톱에서는 우측 건물 상세 카드와 동시 열람 가능), Firebase Firestore 기반 실시간 댓글을 지원해 로그인 없이 닉네임만으로 다른 기기·사용자와 후기를 공유할 수 있습니다.
  - 댓글 작성 시 `1,910동` 건물 검색 자동완성 또는 현재 선택 건물 바로 첨부로 건물을 태그할 수 있으며, **댓글 속 건물 배지를 클릭하면 해당 건물로 지도가 이동하고 동일한 상세 정보 카드가 열립니다**.
  - 건물 상세 카드 하단에서도 해당 건물을 언급한 최신 후기 확인 및 `+ 후기 쓰기` 바로작성이 가능합니다.

## 폴더 구조

```text
mju-housing-map/
├── index.html                 # 메인 진입점 (GitHub Pages 호환 상대경로)
├── .nojekyll                  # GitHub Pages Jekyll 비활성화
├── .gitignore
├── css/
│   └── style.css              # 명지 블루 포인트 테마 및 반응형 드로어 UI
├── js/
│   ├── app.js                 # 상태 관리, 7요소 가중 계산, 필터, 상세 패널
│   ├── comments.js            # Firebase Firestore 실시간 댓글 · 건물 언급/이동 연동
│   ├── mapRenderer.js         # Leaflet + GPU 동기화 Canvas 건물 렌더러 & 히트 테스트
│   └── colorScale.js          # 통합 RdYlGn(빨강→노랑→초록) 컬러 램프 및 포맷터
├── data/
│   ├── buildings.json         # 주거용 건물 1,910동 (WGS84 폴리곤 + 7개 점수 + 메타)
│   ├── context.json           # 행정동 경계 및 용인경전철·주요시설 컨텍스트
│   ├── micro_zones.geojson    # 7개 세부 생활권 통계 폴리곤
│   ├── roads_rent.geojson     # 실거래 기반 47개 도로 평균 환산월세
│   ├── weights_presets.json   # 설문·시나리오 가중치 프리셋
│   └── manifest.json          # 데이터셋 메타데이터
└── scripts/
    └── build_site_data.py     # 통합 GIS 산출물에서 data/ 재생성용 스크립트
```
